- 파일에서 3과목 점수를 입력 받아 총점과 평균점수를 계산하여
	- output.txt 파일에 다음처럼 출력하는 코드를 작성하시오.
```input.txt
홍길동 95 99 96
김길동 80 85 94
이길동 92 76 93
```

홍길동 290 96.7
김길동 259 86.3
이길동 261 87.0
