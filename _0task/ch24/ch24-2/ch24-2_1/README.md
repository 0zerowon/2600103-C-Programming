- 키보드로부터 3명의 이름, 학번, 학점을 입력 받아 변수에 저장하고
- 다음 파일(result.txt)처럼 파일에 출력하는 프로그램을 작성하시오.
```
이름, 학번, 학점 입력: 홍길동 2301 4.5
이름, 학번, 학점 입력: 김길동 2302 3.5
이름, 학번, 학점 입력: 이길동 2303 2.5
```
```result.txt
홍길동 2301 4.5
김길동 2302 3.5
이길동 2303 2.5
```
