- 주소에 의한 호출을 사용해야하는 3가지 경우를 설명하라
	- 다른 함수의 지역 변수를 해당 함수를 호출할 때 인자로써
	  - 해당 피 호출 함수의 매개변수로 전달하여 
	  - 호출한 다른 함수의 지역 변수의 값을 직접 변경할 때
	  	- 포인터 매개변수
	- 배열을 함수 호출할 때 함수의 인자로써 호출한 함수의 매개변수에 전달할 때
		- 배열의 이름은 해당 배열의 첫 원소의 주소
			- 매개변수를 배열로 받으면 인자와 같은 크기의 매개변수를 메모리에 할당하여 성능 낭비
				- 매개변수를 포인터로 받으면 배열의 첫 번째 원소의 주소로 모든 원소에 접근 가능하고
					- 배열의 크기만큼 메모리에 더 할당할 필요 없이 운영체제 크기에 따라 4/8 바이트만 할당
	- return 값이 두 개 이상 필요할 경우
		- return 대신
			- 해당 함수를 호출할 때 인자로써 사용된 다른 함수의 지역 변수를
			- 호출한 함수의 포인터 매개변수로 포인트 연산을 하여 가르키는 변수의 값인 다른 함수의 지역 변수로 변경할 때
- 최대값 구하는 알고리즘을 설명하라
	- 배열의 경우
		- 먼저 첫 원소의 값을 다른 변수에 저장하고
		- for문으로 모든 원소를 참조할 때까지 반복할 때
			- 첫 원소의 값을 저장한 변수를 if문으로 각 원소 마다 비교할 때
				- 그 변수에 더 큰 값으로 대입

	- 상수로 변경되지 않아야 하는 값을 저장할 때 사용
	- 휴먼 에러 방지를 위해 사용
