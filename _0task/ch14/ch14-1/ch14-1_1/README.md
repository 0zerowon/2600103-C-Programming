- 함수의 인자와 매개변수의 차이를 설명하라.
	- 인자는 함수를 호출할 때 사용하는 것
	- 매개변수는 함수 호출 시 인자를  
- 함수가 호출될 때 컴퓨터에 의해 자동으로 실행되는 2가지를 설명하라.
	- 변수를 해당 함수의 매개변수로 사용
	- 메모리 할당 및 인자로 초기화하고 매개변수로 작업을 시행
- 값에 의한 함수 호출방식의 문제점을 설명하라.
	- 리턴이 없으면 호출한 인자의 변수가 변경되지 않으며
	- 리턴한 값을 인자의 변수에 대입 연산자를 사용해야 함
- 주소에 의한 함수 호출방식이 필요한 경우를 설명하라.
	- 매개변수로 넘겨준 변수 값을 원본을 직접 변경할 때 필요함
