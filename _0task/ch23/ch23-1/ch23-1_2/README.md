- 이름, 점수를 멤버로 가지는 구조체를 정의하고
	- 다음처럼 3명의 정보를 키보드로부터 입력 받아
		- 최우수 학생을 구하여 화면에 출력하는 프로그램을 작성하라.
- typedef를 반드시 사용하고
- 키보드로부터 정보를 입력받아 구조체 배열에 저장하는 부분을 함수 get_data으로 만들고
- 구조체 배열에서 최우수 학생의 데이터를 리턴하는 함수를 get_best으로 만들고
- 나머지는 메인 함수에서 처리하라.
- 함수의 선언, 정의, 호출을 사용하라.

성적을 입력하시오: 75\n

성적을 입력하시오: 85\n
