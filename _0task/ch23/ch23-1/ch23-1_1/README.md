- 이름, 학번, 주소를 멤버로 가지는 구조체를 정의하고
	- 다음처럼 키보드로부터 정보를 입력 받아
		- 화면에 출력하는 프로그램을 작성하라.
- 단, 키보드로부터 정보를 입력 받는 부분을 get_data함수로 작성하고
	- 구조체정보를 출력하는 부분을 put_data함수로 작성하라.
- 함수의 선언, 정의, 호출을 사용하라.
- 또, typedef를 반드시 사용하라.

```
학번을 입력하시오: 192040\n
이름을 입력하시오: 홍길동\n
주소를 입력하시오: 군산시 대학로 558\n

1.학번: 192040
2.이름: 홍길동
3.주소: 군산시 대학로 558
```
