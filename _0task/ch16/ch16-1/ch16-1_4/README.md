- 문자열 길이 10의 4개의 문자열을 저장할 2차원 배열 선언
- i, j 변수 선언 및 j를 0으로 초기화

<br>

```c
	for (i = 0; i < 4; i++) 
	{
		printf("%d번째 문자열 입력: ", i + 1);
		scanf("%s", &str[i][0]);
	}
```
- 반복문 시작
	- i를 0으로 초기화하고 4보다 작은 동안 반복
		- "%d번째 문자열 입력: " 출력
			- "%d" == i + 1
				- 인덱스가 0부터 시작하므로 1을 더해줌
		- scanf 함수로 사용자로부터의 문자열 입력을 str[i]에 저장
			- &str[i][0] == i번째 행의 시작 주소
		- i++
- 반복문 종료

<br>

```c
	for (i = 0; i < 4; i++)
	{
		while (str[i][j] != '\0')
		{
			j++;
		}
		printf("%d번째 문자열 길이: %d\n", i + 1, j);
		j = 0;
	}
```
- 외부 반복문 시작
	- i를 0으로 초기화하고 4보다 작은 동안 반복
		- 내부 반복문 시작
			- str[i][j]가 널 문자('\0')가 아닌 동안 반복
				- j++
		- 내부 반복문 종료
		- "%d번째 문자열 길이: %d" 출력 후 개행
			- "%d" == i + 1
				- 인덱스가 0부터 시작하므로 1을 더해줌
			- "%d" == j
				- j는 문자열의 길이를 나타냄
		- j를 0으로 대입
		- i++
- 외부 반복문 종료
