- 배열명의 의미를 설명하라.
  - 해당 배열의 첫 번째 원소의 주소 값을 의미
- 배열 표현과 포인터(주소) 표현의 변환 공식을 설명하라.
  - &arr[i] == arr + i
    - 배열 이름 arr은 배열의 첫 번째 원소인 arr[0]의 주소를 의미하여 &arr[i]는 포인터 연산으로 arr + i로 변환할 수 있고,
      - arr + i: 배열 첫 번째 원소의 주소에 i * (배열 자료형 크기)를 더한 값을 의미하여 배열의 i번째 원소의 주소를 의미함
  - arr[i] == *(arr + i)
    - arr[i]는 arr의 포인터 연산에 간접 참조 연산자를 한 *(arr + i)로 변환할 수 있음
- 배열의 첫 번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있다. 방법을 설명하시오.
  - 배열은 연속된 메모리 공간에 저장되기에 각각의 배열의 원소 주소는 배열의 자료형 크기만큼 떨어져 있어
  - 첫 번째 원소의 주소에 배열의 자료형 크기 * i를 더하면 i번째 원소의 주소를 계산할 수 있음
- 배열의 첫 번째 요소의 주소만 알면 모든 원소의 값를 계산할 수 있다. 방법을 설명하시오.
  - 배열은 연속된 메모리 공간에 저장되기에 각각의 배열의 원소 주소는 배열의 자료형 크기만큼 떨어져 있어
  - 첫 번째 원소의 주소에 배열의 자료형 크기 * i를 더하면 i번째 원소의 주소를 계산할 수 있기에
  - 계산한 주소에 간접 참조 연산자를 사용하여 i번째 원소의 값을 계산할 수 있음
- 포인터에 대해 가능한 연산의 종류와 의미를 설명하라.
  - 덧셈 연산: 포인터에 정수를 i를 더하면 포인터가 가리키는 자료형의 크기 * i를 더한 만큼의 주소를 의미함
  - 뺄셈 연산: 포인터에 정수를 i를 빼면 포인터가 가리키는 자료형의 크기 * i를 뺀 만큼의 주소를 의미함
  - 증감 연산: 증가 연산자를 사용하면 포인터가 가리키는 자료형의 크기만큼 증가한 주소를, 감소 연산자를 사용하면 포인터가 가리키는 자료형의 크기만큼 감소한 주소를 의미함
- 포인터 연산을 기존의 산술 연산과 다르게 정의한 이유는 무엇일까?
  - 메모리 주소 값을 다루기에 자료형의 크기를 고려해야 함
