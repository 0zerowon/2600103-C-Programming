- 함수 선언, 호출, 정의를 각각 설명하라
	- 함수 선언은 main 함수 전에 코드 영역에 전처리기가 저장
	- 함수 호출은 다른 함수에서 해당 함수를 실행
	- 함수 정의는 해당 함수 호출 시 실행할 코드를 나열
- 함수의 자료형은?
	- 함수 자료형(매개 변수 자료형)
- 함수명의 자료형은?
	- 함수 자료형 (*)(매개 변수 자료형)
- void 포인터의 용도는?
	- 자료형에 상관하지 않고 모든 종류의 주소를 저장할 수 있어 메모리 절약 가능
- void 포인터에 간접 참조 연산을 적용할 때 주의할 점은?
	- 자료형을 알 수 없으므로 강제 형 변환 후 간접 참조 연산자를 사용
- 강제형변환과 자동형변환을 설명하시오
	- 강제 형 변환은 프로그래머가 지정하여 자료형을 강제로 변환하는 것
	- 자동 형 변환은 컴파일러가 자동으로 자료형을 변환하는 것
