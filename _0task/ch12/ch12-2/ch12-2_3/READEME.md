- ①번 라인에서 강제 형변환이 사용된 이유를 설명하라.
  - 포인터는 16진수로 주소 값을 할당하므로 16진수 125로 초기화되는 걸 방지하기 위해 int형 포인터로 강제 형변환을 사용
- 아래 코드를 실행하면 오류가 발생하여 중단된다. 이유를 자세히 설명하라
  - 포인터 ptr에 메모리 주소 10을 임의로 할당하여 OS와 컴파일러가 다른 소프트웨어가 사용하고 있는 메모리 주소 값을 사용하면 충돌이 일어나는 걸 방지하기 위해 중단

```c
#include <stdio.h>
int main(void)
{
	int* ptr = (int*)125; // ①
	*ptr = 10;
	printf("%d\n", *ptr);
	return 0;
}
```
