- ①번 라인에서 강제 형변환이 사용된 이유를 설명하라.
  - 125는 int이고 ptr은 int* 때문에 타입이 맞지 않아 int*로 강제 형변환을 사용
- 아래 코드를 실행하면 오류가 발생하여 중단된다. 이유를 자세히 설명하라
  - 포인터 ptr이 가리키는 메모리 주소인 125번지는 OS로부터 허가되지 않은 주소에 10의 값을 할당하려 해서 OS의 메모리 보호 기능으로 강제 종료

```c
#include <stdio.h>
int main(void)
{
	int* ptr = (int*)125; // ①
	*ptr = 10;
	printf("%d\n", *ptr);
	return 0;
}
```
