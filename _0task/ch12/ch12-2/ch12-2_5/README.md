# 소스 코드 설명

```c
#include <stdio.h>
```
- C 표준 라이브러리 input, output 함수의 선언을 포함하고 있는 헤더 파일 stdio.h를 포함

<br>

```c
int main()
```
- main 함수 시작

<br>

```c
int a = 9, b = 10;
int* p_a = &a;
int* p_b = &b;
```
- int형 변수 a, b를 선언 후 각각 9, 10로 초기화
- int형 포인터 p_a, p_b를 선언 후 각각 주소 연산자를 사용한 a, b의 주소값으로 초기화

<br>

```c
printf("a: %d, b: %d\n", a, b);
printf("&a: %p, &b: %p\n", &a, &b);
```
- 문자열을 출력하는 printf 함수를 2번 사용하여
  - 각각 첫 번째 인자로 문자열 "a: , b: ", "&a: , &b: " 출력할 때
	- 서식 문자열을 각각 %d, %p로 출력, 이스케이프 시퀀스 \n로 개행하고
  - 각각 두 번째 인자로 서식 문자열의 %d에 해당하는 a, b와 %p에 해당하는 주소 연산자를 사용하여 a, b 출력

<br>

```c
*p_a = *p_b;
p_a = p_b;
(*p_a)++;
```
- 포인터 p_a가 가리키는 변수 a에 포인터 p_b가 가리키는 변수 b의 값 10 대입
- 포인터 p_a에 포인터 p_b에 할당되어 있는 주소값 &b 대입
- 포인터 p_a가 가리키는 변수 b의 값을 1 증가

<br>

```c
if (*&p_b == p_a)
{
    printf("*&p_b == p_a\n");
}
```
- 포인터 p_b의 주소가 가르키는 값인 p_b에 할당되어 있는 주소값 &b와 포인터 p_a에 할당되어 있는 주소값 &b가 같으면
  - 문자열 	"*&p_b == p_a" 출력, 이스케이프 시퀀스 \n로 개행

<br>

```c
printf("a: %d, b: %d\n", a, b);
printf("p_a: %p, p_b: %p\n", p_a, p_b);
```
- 문자열을 출력하는 printf 함수를 2번 사용하여
  - 각각 첫 번째 인자로 문자열 "a: , b: ", "p_a: , p_b: " 출력할 때
	- 서식 문자열을 각각 %d, %p로 출력, 이스케이프 시퀀스 \n로 개행하고
  - 각각 두 번째 인자로 서식 문자열의 %d에 해당하는 a, b와 %p에 해당하는 p_a, p_b 출력
