- 아래의 변수가 표처럼 메모리가 할당될 때 다음표의 빈칸을 채우시오. 

```c
char ch = 'A';
int in = 10;
double db = 3.4;
```

| :---: | :---: |
| 100 | ch |
| 101 | in |
| 102 | in |
| 103 | in |
| 104 | in |
| 105 | db |
| 106 | db |
| 107 | db |
| 108 | db |
| 109 | db |
| 110 | db |
| 111 | db |
| 112 | db |

| 수식 | 결과값 | 결과값의 자료형 |
| --- | --- | --- |
| &ch | 100 | char* |
| &in | 101 | int* |
| &db | 105 | double* |
