- 스트림과 버퍼의 역할을 각각 설명하시오.
	- 스트림은 프로그램과 입출력 장치의 데이터의 이동 경로를 담당하여 입력 스트림과 출력 스트림이 있음
	- 버퍼는 스트림 내부에 포함되어 입출력 장치와 프로그램 사이에 존재하여 데이터를 임시로 저장하는 메모리 공간
- 버퍼를 사용하여 얻는 장점과 단점을 모두설명하시오.
	- 입력 스트림으로 한꺼번에 버퍼에 저장하여 출력 스트림을 통해 출력 버퍼의 데이터를 한꺼번에 출력할 수 있어 효율적
	- 사용자 입장에서 즉시 데이터를 입출력할 수 없어 속도가 느릴 수 있음
- 입력 버퍼에 데이터가 이미 존재할 때 scanf 함수를 호출한다면 어떤 일이 발생하는가?
	- 추가로 입출력 장치의 입력을 받지 않고 입력 버퍼에 이미 존재하는 데이터를 scanf의 인자 중 변수의 주소가 가르키는 변수에 할당 해버림
- 운영체제가 어떤 경우에 출력 버퍼의 데이터를 모니터로 출력하는가?
	- 버퍼가 가득 차거나 출력 스트림으로 문자 입력이 완료됐을 때
- scanf 함수와 printf 함수 실행시 함수와 운영체제의 역할분담에 대하여 설명하라.
	- 함수는
		- 운영체제 함수는 호출하고 대기
	- 운영체제는
		- 키보드에서 입력 스트림으로 입력 버퍼까지 버퍼에 저장
		- 출력 버퍼에서 출력 장치까지 출력 스트림으로 출력 장치로 출력
