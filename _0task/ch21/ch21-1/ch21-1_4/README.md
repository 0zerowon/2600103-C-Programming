	- 19, 21페이지의 그림처럼 반복문 실행단계별로 버퍼의 상태를 그리고 설명하라.

```c
#include <stdio.h>
int main(void)
{
	char ch;
	int i;
	for (i = 0; i < 5; i++)
	{
		printf("문자 입력: ");
		scanf("%c", &ch);
		printf("문자: %c\n", ch);
	}
	return 0;
}
```
